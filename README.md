# Песни на русском с Suno

Из одной идеи или черновика собери название, стиль и слова песни. Подготовить их можно в ChatGPT, Claude или другом ИИ. Готовые поля принимает [@TairMusicBot](https://t.me/TairMusicBot).

## Начни с одного промпта

Скопируй весь блок и отправь в свой чат с ИИ. Можешь сразу добавить свою идею, готовые строки или пожелания к правке.

```text
Изучи https://github.com/rubigotrafikcash-gif/russian-songs-for-suno
Если у меня пока только идея, задай один короткий вопрос о том, чего не хватает для песни. Если данных достаточно, начни писать. Если я прислал готовый текст и указал задачу, сразу выполни её. Если прислал только текст, спроси, что я хочу с ним сделать. При добавлении тегов сохрани мои слова и порядок строк. Если ссылка не открывается, продолжай по моему сообщению.

Когда я попрошу подготовить песню для @TairMusicBot, дай отдельные блоки Title, Styles и Lyrics. Styles напиши на английском. Для инструментала дай только Title и Styles.
```

Для ИИ, который открыл репозиторий. Прочитай [SKILL.md](SKILL.md) и [плейбук](PLAYBOOK.md), проверь формат по [примеру](EXAMPLE.md). Если GitHub показывает только список файлов, открой [текст навыка](https://raw.githubusercontent.com/rubigotrafikcash-gif/russian-songs-for-suno/main/SKILL.md). Затем определи по сообщению, нужна ли помощь с идеей, правкой готовых строк или разметкой. Инструкции по подключению есть [в самом навыке](SKILL.md#как-подключить-навык).

Посмотри, как одна семейная деталь превращается в припев, в [примере поздравления мамы с днём рождения](EXAMPLE_BIRTHDAY.md).

## Перенеси результат

1. В [@TairMusicBot](https://t.me/TairMusicBot) выбери «Вокал» или «Инструментал».
2. По подсказкам бота вставь содержимое блоков по одному. Сначала **Title**, затем **Styles**, потом **Lyrics** для вокала. Для инструментала хватит названия и стиля.
3. После прослушивания выбери один фрагмент, который хочешь улучшить, и вернись в тот же чат с ИИ. [Плейбук](PLAYBOOK.md#5-проверь-первый-дубль)

Поля также можно перенести напрямую в режим **Custom** в Suno. [Suno Create](https://suno.com/create) · [Справка Suno](https://help.suno.com/en/articles/2415873)

Универсальные материалы TairMusic для авторов песен. Жанр, тема и форма выбираются по вашему замыслу. Навык сохраняет авторские строки и смысл, помогает проверить язык, рифму и ритм; не требует личных пресетов или установки дополнительных инструментов. Русское пояснение Styles, если оно добавлено после полей, предназначено для сверки — в бота переносится английский блок.
