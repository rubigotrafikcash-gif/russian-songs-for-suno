# Песни на русском с Suno

Из одной идеи или черновика собери название, стиль и слова песни. Подготовить их можно в ChatGPT, Claude или другом ИИ. Готовые поля принимает [@TairMusicBot](https://t.me/TairMusicBot).

## Начни с одного промпта

Скопируй весь блок и отправь в свой чат с ИИ. Он откроет материалы и задаст вопросы о песне.

```text
Изучи https://github.com/rubigotrafikcash-gif/russian-songs-for-suno
Подключи навык, если нужно. Расспроси меня о песне, даже если ссылка недоступна. По ответам выдай отдельные блоки Title, Styles, Lyrics для @TairMusicBot. Инструментал — без Lyrics.
```

Для ИИ, который открыл репозиторий. Прочитай [SKILL.md](SKILL.md) и [плейбук](PLAYBOOK.md), проверь формат по [примеру](EXAMPLE.md). Если GitHub показывает только список файлов, открой [текст навыка](https://raw.githubusercontent.com/rubigotrafikcash-gif/russian-songs-for-suno/main/SKILL.md). Затем задай вопросы о песне. Инструкции по подключению есть [в самом навыке](SKILL.md#как-подключить-навык).

## Перенеси результат

1. В [@TairMusicBot](https://t.me/TairMusicBot) выбери «Вокал» или «Инструментал».
2. По подсказкам бота вставь содержимое блоков по одному. Сначала **Title**, затем **Styles**, потом **Lyrics** для вокала. Для инструментала хватит названия и стиля.
3. После прослушивания выбери один фрагмент, который хочешь улучшить, и вернись в тот же чат с ИИ. [Плейбук](PLAYBOOK.md#5-проверь-первый-дубль)

Поля также можно перенести напрямую в режим **Custom** в Suno. [Suno Create](https://suno.com/create) · [Справка Suno](https://help.suno.com/en/articles/2415873)

Универсальные материалы TairMusic для авторов песен. Жанр, тема и форма выбираются по вашему замыслу. Навык сохраняет авторские строки и смысл, помогает проверить язык, рифму и ритм; не требует личных пресетов или установки дополнительных инструментов. Русское пояснение Styles, если оно добавлено после полей, предназначено для сверки — в бота переносится английский блок.
